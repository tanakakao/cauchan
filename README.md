# cauchan

`cauchan` は、表形式データから因果構造を探索し、推定結果を可視化する
Streamlit アプリケーションです。CSV または Excel ファイルをアップロードし、
変数やアルゴリズム、事前知識を画面上で指定できます。

## 主な機能

- DirectLiNGAM / PC による数値変数の因果探索
- GES / HillClimbSearch によるカテゴリ変数を含む因果探索
- 禁止エッジ、既知エッジ、原因・結果にしない変数の指定
- 隣接行列のヒートマップと因果ネットワークの可視化
- SCM（線形回帰）または LinearDML による介入効果の推定

## 必要環境

- Python 3.10 以上 3.12 以下
- 対応入力形式: `.csv`、`.xlsx`

因果探索・推論ライブラリには機械学習フレームワークを含む依存関係があるため、
仮想環境の利用を推奨します。

## セットアップ

リポジトリのルートディレクトリで、プロジェクト用の仮想環境を作成します。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

Windows PowerShell では、仮想環境を次のコマンドで有効化します。

```powershell
.venv\Scripts\Activate.ps1
```

## 起動方法

```bash
streamlit run main.py
```

コマンド実行後、ターミナルに表示される URL をブラウザで開きます。

## 使い方

1. CSV または Excel ファイルをアップロードします。
2. 因果探索に使うカラムを 2 つ以上選択します。
3. 必要に応じてカテゴリ変数と事前知識を指定します。
4. アルゴリズムを選び、**計算開始**を押します。
5. ヒートマップとネットワークで推定された因果構造を確認します。
6. 2 変数と推定手法を選び、**推論開始**を押すと介入効果を確認できます。

カテゴリ変数を選択しない場合は DirectLiNGAM または PC、選択した場合は GES
または HillClimbSearch を利用できます。CSV の文字コードは UTF-8、Shift_JIS、
CP932 に対応しています。

## ファイル構成

```text
.
├── main.py          # Streamlit UI
├── model.py         # 因果探索と因果効果推定
├── visualization.py # ヒートマップと因果ネットワークの可視化
└── pyproject.toml   # パッケージ情報と依存関係
```

## 注意事項

- 推定結果は、利用するデータ、アルゴリズム、および事前知識に依存します。
- 得られた因果関係は仮説として扱い、ドメイン知識や追加検証と組み合わせてください。
- 大規模なデータや一部の探索アルゴリズムでは、計算に時間がかかる場合があります。
